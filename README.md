# <sup>Relics</sup> of <sub>Rain</sub>

This mod is an addon to the <a href="https://github.com/Octo-Studios/relics">Relics mod made by Octo-Studios</a>.
Features from this mod are inspired from a game called Risk of Rain. Some items are a direct copy, while other are merely an inspiration.
